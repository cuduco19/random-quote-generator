# Random Quote Generator

A fast, resilient, and accessible quote generator built with modular vanilla JavaScript, exponential backoff retry logic, `localStorage` history, an `esbuild` asset pipeline, and automated Jest unit tests.

## Live Demo

- **Live Site:** [https://evancru-random-quote-generator.netlify.app](https://evancru-random-quote-generator.netlify.app)

## Features

- **Dynamic Quote Fetching:** Asynchronously fetches random quotes from the [DummyJSON Quotes API](https://dummyjson.com/quotes/random).
- **Resilient Networking:** Features exponential backoff retry logic with equal jitter and a fallback to curated local quotes.
- **Persistent History:** Saves the last 10 unique quotes in `localStorage` with keyboard navigation support.
- **Sharing Tools:** Copy quotes to the clipboard or share directly to X (Twitter).
- **Accessibility & Performance:** Semantic markup, `aria-live` announcements, focus management, and zero layout shift (96+ Lighthouse score).
- **Testing:** Includes a 10-test Jest and `jsdom` test suite (with custom `esbuild` ES module transformation) covering rendering, storage, and API fallbacks.

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd random-quote-generator
   ```
2. **Install dependencies & run tests:**
   ```bash
   npm install
   npm test
   ```
3. **Build and preview:**
   ```bash
   npm run build
   ```
